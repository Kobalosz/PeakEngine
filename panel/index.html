How

The item list loads once the game has started.

These work whether or not you are the host. Try one on yourself first to see what it does. Want to drop something on a friend's head? Use “Drop on their head” on the Items tab.

Does PeakEngine still match your game version?

PeakEngine finds things in the game by name. When PEAK updates, a name can change and the feature that used it stops working. A row marked “missing” tells you which one. See docs/05-troubleshooting.md for how to fix it.
